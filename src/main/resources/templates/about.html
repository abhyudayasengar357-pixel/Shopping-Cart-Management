University OOPs Using Java Case Study

System Architecture & OOP Concepts Mapping

Comprehensive mapping of all mandatory Object-Oriented Programming (OOP) concepts to actual production components within this application.

1. Classes & Objects

Real-world domain models represented as clean Java classes containing state (fields) and behavior (methods).

Code Examples:
  • Product.java: Models merchandise in catalog
  • Order.java, OrderItem.java: Purchase orders
  • Cart.java, CartItem.java: User shopping sessions
2. Encapsulation

Data hiding through private and protected member fields with access mediated exclusively through public getters, setters, and validation methods.

Code Examples:
  • Product.reduceStock(): Validates inventory invariants before mutation
  • User.java: Sensitive attributes like hashed passwords are encapsulated
3. Inheritance

Code reuse and hierarchical specialization via the extends keyword.

Code Examples:
  • BaseEntity: Inherited by User, Product, Order, Category for common ID & timestamps
  • Customer extends User, Admin extends User
  • PercentageDiscountStrategy extends AbstractDiscountStrategy
4. Polymorphism

Both Compile-Time Polymorphism (Method Overloading) and Runtime Polymorphism (Dynamic Method Dispatch & Interfaces).

Code Examples:
  • Runtime: DiscountStrategy.calculateDiscount() implemented differently in PercentageDiscountStrategy and FlatDiscountStrategy
  • Runtime: PaymentProcessor implemented by CardPaymentProcessor, UPIPaymentProcessor, CashOnDeliveryProcessor
  • Compile-time: ProductService.searchProducts() overloaded with multi-criteria signatures
5. Abstraction

Hiding implementation details and exposing clean contracts using abstract classes and interfaces.

Code Examples:
  • Interfaces: ProductRepository, UserRepository, OrderRepository, DiscountStrategy, PaymentProcessor
  • Abstract Classes: BaseEntity, AbstractDiscountStrategy
6. Constructors & Chaining

Default, parameterized, and overloaded constructors demonstrating constructor chaining using this(...) and super(...).

Code Examples:
  • User.java: Multiple constructors chained using this(...)
  • Customer.java, Admin.java: Superclass constructor calls using super(...)
7. Method Overriding

Redefining superclass or interface methods in subclasses annotated with @Override.

Code Examples:
  • Customer.getRoleDescription() overrides User.getRoleDescription()
  • Product.compareTo() overrides Comparable<Product> for sorting
  • BaseEntity.equals() and hashCode()
8. Exception Handling

Custom application exception hierarchy rooted in CartException with centralized handler.

Code Examples:
  • InsufficientStockException: Handled gracefully during cart & checkout operations
  • ResourceNotFoundException, AuthenticationException, DatabaseOperationException
  • GlobalExceptionHandler: Spring @ControllerAdvice
9. Java Collections & Streams API

Extensive use of the Java Collections Framework (List, Set, Map) and Java Streams for declarative processing.

Code Examples:
  • Cart.calculateSubtotal(): items.stream().map(CartItem::getSubtotal).reduce(BigDecimal.ZERO, BigDecimal::add)
  • DiscountCalculator.strategies: Map<String, DiscountStrategy> for O(1) coupon resolution
  • OrderService.paymentProcessors: Map<PaymentMethod, PaymentProcessor>
